# 비기능 명세 (NFR)

## 보안·개인정보

- **NFR-SEC-001 (MUST):** Renderer는 Node API에 직접 접근하지 못한다. Electron `contextIsolation`, `sandbox`, 최소 권한 preload, 엄격한 IPC 검증 적용.
- **NFR-SEC-002 (MUST):** API/웹훅 키를 로그/채팅/에러 리포트/저장소에 포함하지 않는다. OS 보호 저장소를 사용하고 UI에서는 마스킹.
- **NFR-SEC-003 (MUST):** 캡처/조작은 기본 OFF, 명시적 요청·정확한 범위·유효기한/승인; 고위험 도구는 추가 확인.
- **NFR-SEC-004 (MUST):** Callback은 인증·재생 공격 방지·만료·크기 제한·request correlation을 검증.
- **NFR-SEC-005 (MUST):** 원격 텍스트를 Shell 명령/HTML로 직접 실행하지 않는다. CSP, sanitize, URL allowlist 적용.

## 신뢰성·복구

- **NFR-REL-001:** 요청 상태와 terminal 이벤트는 정확히 한 번 UI에 반영하며 중복 메시지를 제거.
- **NFR-REL-002:** 비동기 공급자의 결과 미도착은 '대기/타임아웃'으로 표현, 성공으로 오인하지 않음.
- **NFR-REL-003:** 네트워크 장애·앱 재시작 후 원격 실행 여부가 불명확하면 자동 재요청 금지.
- **NFR-REL-004:** TTS 실패 시 텍스트 답변은 유지, 모델 모션 누락 시 idle fallback.

## 성능(목표, 실측 전 임시값)

- **NFR-PERF-001:** 단일 중간급 모델/일반 Windows 11 PC에서 캐릭터 렌더 목표 60 FPS, 30 FPS 저전력 옵션; 측정 조건 기록 필수.
- **NFR-PERF-002:** UI 이벤트와 애니메이션은 네트워크 응답과 독립적으로 부드럽게 유지.
- **NFR-PERF-003:** 실시간 공급자의 첫 텍스트 델타 지연 및 첫 음성 재생 지연은 PoC 측정 후 목표 확정; 외부 봇 처리 시간을 로컬 앱 성능 지표에 혼합하지 않음.
- **NFR-PERF-004:** 메모리/CPU/GPU 사용량은 모델별 편차를 기록하여 회귀 기준선 마련.

## 호환성·사용성

- **NFR-COMP-001:** Windows 11 x64 지원을 첫 릴리스 기준. 다른 OS는 구현 전 검증 요구.
- **NFR-COMP-002:** Live2D 모델에서 없는 파라미터/모션은 건너뛰고 진단 제공.
- **NFR-UX-001:** 키보드 중심 채팅, 탭 이동, 스크린 리더용 승인/상태 텍스트를 설계.
- **NFR-UX-002:** 에이전트별 '지원됨/실험적/미지원' 및 연결 상태를 사용자에게 표시.

## 데이터 처리

- **NFR-DATA-001:** 기본 로컬 저장은 연결 메타데이터와 UI 설정만. 메시지·음성·캡처 저장은 명시적으로 설정.
- **NFR-DATA-002:** 에이전트별 저장/삭제/보존 단위를 분리. 원격 공급자 기록 삭제를 로컬 삭제와 동일하다고 주장하지 않음.
- **NFR-DATA-003:** 민감한 캡처와 TTS 원문을 텔레메트리에 포함하지 않는다.

각 NFR의 측정 방법은 `docs/testing/TEST_STRATEGY.md` 참조. 숫자 목표는 하드웨어·모델·엔진 조건이 밝혀질 때 ADR로 확정한다.
