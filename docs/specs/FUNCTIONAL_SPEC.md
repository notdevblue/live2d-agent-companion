`FR-L2D-008` (P1): 쓰다듬기는 저장 가능한 명시적 `pettingEnabled` 설정(기본 꺼짐)과 Shift+왼쪽 입력으로만 제공 MUST. 자기 canvas의 알파 실루엣 상단 40%에서 직접 문지르는 입력을 사용하며 해부학적 머리 인식으로 표시하지 않는다. 접촉 중의 로컬 좌표로 시선·고개를 부드럽게 향하고, 사용자 홍조 매핑의 안전한 표시 층만 합성한다. 일반 클릭·이동·휠 배율과 구분하고 요청·승인 중 차단한다. 정지·상단 이탈·키 해제·pointerup/cancel/lostcapture·blur·설정 해제·새 요청·승인·오류에서 복귀하며 최대 12초로 제한한다. 외부 호출·전역 커서 추적·PC 입력 실행·화면 캡처를 추가하지 않는다. 검증된 기본 paired 손 자산과 정확한 입력 범위가 있고 기존 손이 비어 있을 때에만 직접 유효 stroke에 원본 가슴 손 포즈를 함께 쓸 수 있다. 사용자 다른 매핑·빈 선택·움직임 줄이기·부족한 자산은 몸/얼굴만 사용한다. 이는 활성 의미 cue의 `gesture=none`에서 감정만으로 팔을 자동 재생하는 동작과 구별한다. 독립 idle 손 중 시작한 접촉은 기존 손과 기한을 유지하고 그 접촉 동안 몸/얼굴만 반응한다. 접촉 종료로 다른 소유자의 idle 손을 정리하지 않는다.

`FR-L2D-009` (P1): 무음 시각 연기는 감정과 말투의 복합 의도를 고개·시선·눈·입으로 구별 MUST. 기쁨과 대기, 걱정 섞인 장난과 장난, 시선 회피 후 웃음을 구별하고 강조→여운→복귀를 시간 기반으로 진행한다. 특수 눈 아트는 짧은 강조 뒤 다른 표시 층과 독립 복귀하며, 화남·혼란은 입을 닫는다. 긴 손 유지 중에도 유한한 얼굴·시선 반응을 제공하고 두 번째 변주는 강조 시점/길이를 달리한다. 없는 채널·authored motion·physics 출력 보호와 움직임 줄이기·기존 수명/clear 경계를 유지한다. 기쁨 cue에 매핑한 눈 아트는2300ms의 유한한 강조 뒤 기존 열린 기쁨 얼굴로 이어지며 laugh/tease/confused의 기존 짧은 강조 우선순위·선택 자산/빈 값·다른 표시 층을 보존한다. 걱정+장난은 과도한 숙임/회피·반눈으로 시선이 포화하지 않도록 조합하고, 닫힌 걱정 얼굴→기존 지연 wink의 작은 미소→걱정 여운을 구분한다. 땀의 authored 표시 주기를 덮어 항상 보이게 만들지 않는다. 순수 angry/gesture none은 기존 강조 시계의 한 번의 눈 확인을 허용하되 고개/몸·찡그린 입·blink·기한을 보존한다. VTuber 매력 점수는 자동 기능 검사의 대체가 아니며 실제 렌더에 대한 주관적 검토로 기록한다.

`FR-L2D-010` (P1): expressive·움직임 줄이기 꺼짐의 활성 cue 없는 idle에 유한한 로컬 몸짓/얼굴 표현을 독립 소유권으로 제공 SHOULD. 기존 불규칙 gaze edge와 시작 시각만 사용하고 새 타이머·랜덤·동작 큐·외부 판단을 추가하지 않는다. 부적격 edge도 소비해 같은 슬롯에서 뒤늦게 재생하지 않는다. actor 반응·기존 pose/gesture/모션·작업/승인·held contact/잔여 petting·normal/quiet/reduced는 차단 MUST. 활성 의미 cue의 `gesture=none`에 감정만으로 손을 추가하지 않고 의미 수명/cooldown·입 열림/호흡/rootY를 보존한다.

독립 idle 손은 네 번째 슬롯 edge에 검증된 원본 pair의 진입/복귀와600ms 유지, 총2750ms로 끝낸다. canonical 매핑·입력/범위/endpoint 및 authored IDLE의 팔 소유권을 검사하고 사용자 custom/빈 선택/부족한 자산을 우회하지 않는다. 같은 pose 가중치의 유한한 미소/눈웃음과 눈 재접촉을 연결할 수 있다. 별도 idle 눈인사는8개 슬롯 중2mod8 edge에250ms 준비/180ms attack/450ms hold/450ms release로1330ms에 끝낸다. smile .5·한 눈 닫힘/반대 눈 .92에 기존 blink를 곱하며 고개/몸/시선/lean·입 열림/호흡/root·자산 시계는 바꾸지 않는다. 자산 없는 절차 얼굴은 hand 매핑과 별개이며 첫 IDLE의 authored 눈꺼풀/MouthForm/EyeSmile/특수 눈 소유권을 보호 MUST.

두 로컬 표현은 semantic cue와 별도 진단 상태이며 actor를 active로 만들지 않는다. blink·특수 눈/자산/physics 소유권·직접 접촉 우선권을 보존한다. 새 cue/승격·요청·상태/접근성 전환·reset/preview/dispose/context loss/렌더 오류는 즉시 정리하고 stale cue·끝난 메시지의 scoped clear는 독립 소유권을 지우지 않는다. 새 pet begin은 눈인사를 즉시 지우되 기존 idle 손·기한은 보존하며, 접촉 종료도 다른 소유자의 idle 손을 정리하지 않는다.

`FR-DIR-006` (P1): 기존 한 번의 Jev 판단에 `angry`/`confused` 감정을 추가 MUST. 화자 자신의 분노·혼란과 사용자/주제의 감정을 구분하고 사실 설명·차분한 숙고는 해당 감정으로 과장하지 않는다. 새 화남 기본은 검증된 눈썹/입 upstream의 로컬 합성, 혼란은 대응 눈 자산이 있으면 사용하고 없으면 로컬 시선·고개로 fallback한다. 미확인 `Emotion`/`Emotion2`/`脱捕`와 새 리깅·새 호출은 추가하지 않는다. 슬픔·걱정·안심·인사·화남·혼란도 기존 로컬 미리보기 권한 경로에 제공한다.

## 에이전트

`FR-CHAT-001` (P0): Hermes SSH에서 선택한 connection/profile/session을 유지하고, 채팅창 재생성·renderer reload·앱 재실행 후 공급자의 표시용 대화를 다시 보여줘야 한다. 사용자/assistant 본문만 읽으며 도구 입출력·reasoning은 제외한다. 기록 복원은 prompt 재전송·Jev 재판단을 발생시키지 않고 다른 binding의 기록을 섞지 않는다. 원격 기록 읽기를 지원하지 않는 공급자에 재시작 복원을 제공한다고 표시하지 않는다.

`FR-CHAT-002` (P0): 실시간/복원 assistant 답변의 Markdown 문단·강조·목록·코드·표를 렌더링하고 사용자 입력은 원문으로 표시한다. HTML 실행·임의 DOM 속성·외부 자원 자동 로드·위험 URL 이동을 허용하지 않는다. 긴 코드/표는 메시지 안에서 스크롤한다.

`FR-CHAT-003` (P0): 사용자가 선택·드롭·붙여넣은 이미지/파일을 초안에서 확인·제거하고 현재 선택한 세션에 명시적 전송한다. 첨부만 전송할 수 있으며 파일당 10 MiB·최대 10개·전체 25 MiB로 제한한다. PNG/JPEG/GIF/WebP는 이미지로, 다른 파일은 일반 파일로 전달한다. renderer 경로를 main/SSH 파일 읽기 권한으로 사용하지 않고 명시적 File 바이트만 처리한다. 공급자의 이미지/파일 지원을 별도 확인하고 미지원 종류는 전송 전에 거절한다. 실패 시 초안 보존, 전환 시 첨부 격리, 불명확한 접수의 자동 재전송 금지와 준비 중 취소를 검사한다. 첨부 원문은 Jev·로컬 로그·pending metadata에 넣지 않는다.
